Algorithm Overview

Infix to Postfix

Shunting-Yard Algorithm by Dijkstra. Uses an operator stack to reorder tokens based on precedence and associativity.

  1. Read token left to right
  2. Operand → output directly
  3. Operator → pop higher/equal precedence ops, then push
  4. ( → push to stack
  5. ) → pop until (
  6. End → pop remaining stack to output

Postfix Evaluation

Stack-based evaluation processes postfix tokens left to right without needing parentheses or precedence rules.

  1. Read token left to right
  2. Operand → push onto stack
  3. Operator → pop two operands
  4. Apply operation: a OP b
  5. Push result back
  6. Final top = answer
